### ***Description***
####  Quiz is single player game for checkig basic education. This is the first project for Software Engineering Immersive @ General Assembly.
***

### ***Technologies Used***
* Javascript
* HTML
* CSS
***

### ***Getting Started***

#### 
* Once ready, click the "Start Quiz" button.
* Read short instructio and satrt answering the questions.
* Main goal is to collect maximum of 15 points.
* Enjoy yourself!
